# Minimalist-Portfolio
Minimalist Portfolio Website
A clean, responsive, and minimalist portfolio website built with only HTML, CSS, and vanilla JavaScript. This project is designed to be a lightweight, single-page application that simulates a multi-page experience through dynamic content rendering.

🚀 Features
Responsive Design: The website is fully responsive and looks great on desktop, tablet, and mobile devices.

Smooth Navigation: A custom JavaScript-powered navigation system allows for seamless transitions between pages without full page reloads.

Dynamic Sections: The homepage includes an "About Me" call-to-action that smoothly scrolls to the relevant section.

Contact Form Validation: The contact form includes client-side validation to ensure all required fields are filled and the email address is in a valid format.

Interactive Elements: All interactive elements, such as buttons and navigation links, have clear hover and focus states.

🛠️ Technologies Used
HTML5: For the semantic structure of the website.

CSS3: For styling, including a custom design system for colors, fonts, and responsive layouts.

JavaScript: For all interactive functionality, including navigation, form validation, and smooth scrolling.

📂 Project Structure
The project is contained within a single index.html file, which includes all HTML, CSS, and JavaScript.

/index.html

📝 How to Use
Save the file: Save the provided code as index.html.

Open in Browser: Open the index.html file in any modern web browser to view the portfolio website.

Contact Form Validation
The contact form has built-in validation to handle common errors:

Empty fields: If the Name, Email, or Message fields are left empty, a "This field is required" message will appear.

Invalid Email: If the email address is not in a valid format, a "Please use a valid email address" message will be displayed.

About the Creator
This project was built to showcase front-end development skills using a minimalist approach. The goal was to create a functional and aesthetically pleasing website without relying on external frameworks or libraries.
